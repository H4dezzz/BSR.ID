# Besurr ID

Buatkan halaman website modern, interaktif, dan fully responsive (Company Profile Landing Page) berdasarkan seluruh informasi yang ada di dalam dokumen "Company Profile Besurr.id".

### 1. Visual Theme & Style Guidelines:
- Aesthetic & Glassmorphism Style (iOS / iPhone Vibe): Gunakan efek frosted glass (backdrop-blur), border semi-transparan yang halus, sudut elemen melengkung (rounded rounded-2xl / rounded-3xl), serta skema warna gelap eksklusif (Dark Mode / Deep Slate & Charcoal) dengan aksen Neon Green (#00FF66 / #10B981) sesuai dengan elemen warna di dokumen.
- Typography: Gunakan font modern bergaya Apple/iOS (seperti 'SF Pro Display', 'Inter', atau system-ui sans-serif) yang bersih, elegan, dan readable.
- Smooth Animations: Terapkan animasi scroll halus (Smooth Scroll / Scroll Reveal), efek hover kartu 3D/Glow, dan transisi antar seksi yang mulus.
- Hero/Background Feature (Network & Fiber Optic Animated Cable): Buat komponen visual interaktif atau latar belakang berupa animasi garis-garis kabel serat optik (SVG/Canvas) dengan efek cahaya/pulsa energi neon murni yang mengalir melintasi layar untuk merepresentasikan konektivitas internet & cloud provider cepat.
